# 아직 남은 문제

- **RFID 거리** — RC522는 실제로 약 2–3 cm에서 읽혀서, 반려동물이 자연스럽게 다가오는 상황에는 너무 짧았습니다.
- **다른 개체의 접근** — 태그를 확인해 문을 열어도 다른 반려동물이 함께 들어오는 상황까지 막지는 못합니다.
- **식사 종료 시점** — 태그가 잠시 안 읽히는 것만으로 식사가 끝났다고 볼 수는 없습니다.
- **사료 차이** — 알갱이의 크기나 모양이 바뀌면 배출 속도와 걸림 정도도 달라집니다.
- **서보 내구성** — 시제품에서 쓴 SG90은 문이 무거워지고 반복 동작이 많아지면 교체가 필요할 수 있습니다.

## 다음에 해 볼 것

- 134.2 kHz RFID Reader와 외부 안테나로 인식 범위를 늘리기
- 거리 센서나 카메라로 누가 급식 공간을 쓰는지 한 번 더 확인하기
- RFID만 보지 않고 무게 변화와 움직임도 함께 보며 식사 종료 판단하기
- 알림음·LED, 섭취량 변화 알림 추가하기
- 여러 급식기 스케줄과 장기 기록을 동기화하기
- 교체형 Auger Screw, 문 구조, actuator 다시 검토하기
