# 프로젝트 개요

ILLO는 여러 반려동물이 함께 사는 집을 위한 자동 급식기입니다. 단순히 정해진 시간에 사료를 내보내는 데서 끝내지 않고, 누가 먹었는지와 얼마나 남겼는지까지 남기려 했습니다.

## 주요 기능

### 개체 식별과 스케줄

목걸이의 RFID 태그를 읽어 등록된 개체인지 확인합니다. 개체별로 급식 시간, 양, 반복 요일을 정할 수 있고, 대상이 아니면 문을 열지 않습니다.

### 정량 배식과 섭취량 기록

사료를 내보내는 동안에는 Load Cell로 그릇 무게를 계속 확인합니다. 목표 양에 도달하면 모터를 멈추고, 식사가 끝난 뒤 남은 양을 다시 재서 실제로 먹은 양을 계산합니다.

```text
실제 섭취량 = 배식량 - 잔량
```

이전 식사에서 남은 양은 다음 배식량을 조절할 때 참고할 수 있습니다.

### 급식 결과 활용

앱에서는 반려동물과 태그를 등록하고, 개체별 스케줄과 급식 결과를 봅니다. 이 정보는 서버에서 관리하며, 서버는 MQTT Broker를 통해 급식기와 메시지를 주고받습니다. 예정 시각과 실제 시각, 설정한 양과 실제 배식량, 잔량을 쌓아 두면 식사 패턴도 확인할 수 있습니다.
